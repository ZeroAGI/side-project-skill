## TIER 1: Open-Source Platforms (High GitHub Star Count, Global Reach)

### 1. RAGFlow (开源 RAG 引擎)
- **GitHub**: ~80,000+ stars
- **License**: Apache 2.0
- **Description**: Leading open-source RAG engine built on deep document understanding
- **Key Features**: DeepDoc parsing engine, GraphRAG with knowledge graph, agent memory, multi-chat-channel support
- **Target**: Enterprises needing high-quality document understanding -- legal, medical, structured documents
- **Source**: [ragflow.io](https://ragflow.io/)

### 2. MaxKB (开源企业级智能体平台)
- **GitHub**: ~20,200+ stars
- **License**: GPLv3
- **Developer**: FIT2CLOUD (飞致云)
- **Description**: Enterprise-grade agents with RAG pipelines, workflow engines, MCP tool capabilities
- **Source**: [maxkb.cn](https://www.maxkb.cn/)

### 3. BISHENG / 毕昇 (开源 LLM DevOps 平台)
- **GitHub**: ~10,300+ stars
- **License**: Apache 2.0
- **Description**: LLM DevOps platform with AGL framework for expert knowledge, Human-in-the-Loop, high-precision document parsing
- **Source**: [dataelem.com](https://www.dataelem.com/)

### 4. One API (大模型 API 管理与分发系统)
- **GitHub**: ~20,000+ stars
- **License**: MIT
- **Description**: Unified API for 20+ LLM providers under OpenAI-compatible endpoint
- **Source**: [github.com/songquanpeng/one-api](https://github.com/songquanpeng/one-api)
